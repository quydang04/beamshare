# Beamshare - P2P File Transfer (Java Version)

✨ **Successfully converted to Java!** ✨

Ứng dụng chia sẻ file P2P được chuyển đổi từ Node.js sang Java Spring Boot.

## 🚀 Quick Start

### Prerequisites
- Java 17+
- Maven 3.6+

### Running
```bash
mvn spring-boot:run
```

Access: http://localhost:3000

## Tính năng

- ✅ Chia sẻ file P2P trực tiếp giữa các máy trong cùng một mạng
- ✅ Real-time progress tracking  
- ✅ Cross-browser compatibility
- ✅ Tối ưu giao diện cho Mobile/Tablet/PC
- ✅ Public room sharing với QR codes
- ✅ Java Spring Boot backend với WebSocket
- ✅ Material Design UI không đổi
